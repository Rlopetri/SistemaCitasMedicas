# Sistema de Administración de Citas Médicas

## Descripción

Aplicación desarrollada en Java para simular un sistema de administración de citas de un consultorio clínico.

El sistema permitirá registrar doctores y pacientes, crear citas con fecha y hora, relacionar cada cita con un doctor y un paciente, y controlar el acceso mediante usuarios administradores.

## Instalación y configuración

1. Instalar Java Development Kit (JDK) 11.
2. Instalar y configurar IntelliJ IDEA.
3. Instalar y configurar Git.
4. Clonar o descargar este repositorio.
5. Abrir el proyecto `SistemaCitasMedicas` en IntelliJ IDEA.
6. Configurar el proyecto para utilizar JDK 11.
7. Ejecutar la clase `Main` para iniciar la aplicación.

## Uso del programa

El sistema permitirá realizar las siguientes operaciones:

- Iniciar sesión mediante un usuario administrador.
- Dar de alta doctores con identificador, nombre completo y especialidad.
- Dar de alta pacientes con identificador y nombre completo.
- Crear citas indicando identificador, fecha, hora y motivo.
- Relacionar cada cita con un doctor y un paciente.
- Consultar la información registrada.
- Almacenar la información del sistema en archivos.
- Manejar errores y excepciones sin finalizar inesperadamente la aplicación.
